# 📊 Sistema de Coleta de Dados do Mercado de Ações

## 📖 Sobre o Projeto
Este projeto foi desenvolvido como trabalho freelancer e tem como objetivo automatizar a coleta de informações do mercado de ações por meio de **web scraping**.  
A aplicação navega em fontes financeiras, coleta e trata os dados, garantindo qualidade e consistência, e gera relatórios prontos para apoiar estratégias e decisões de investimento.

---

## ✨ Funcionalidades Principais
- **Automação de Navegação**: Uso do **Selenium** para simular interação humana (logins, buscas, navegação complexa).  
- **Extração de Dados (Web Scraping)**: Coleta de cotações, volumes, indicadores fundamentalistas e notícias de ativos.  
- **Processamento e Limpeza de Dados**: Tratamento com **Pandas** para garantir integridade e padronização.  
- **Geração de Relatórios**: Consolidação em relatórios estruturados, prontos para envio aos clientes.  

---

## 🛠️ Tecnologias Utilizadas
- **Python** → Lógica principal de automação e processamento.  
- **Selenium** → Automação do navegador em páginas dinâmicas.  
- **Pandas** → Manipulação e limpeza de dados.

# 📚 Projeto de Pesquisa: Livros Mais Vendidos na Amazon

## 📖 Sobre o Projeto
Projeto solo com foco em **web scraping** para coletar dados dos livros mais vendidos na Amazon.  
A aplicação automatiza a navegação, extrai informações relevantes como título, autor, preço e avaliações, e organiza os resultados para análise ou visualização.

---

## ✨ Funcionalidades Principais
- **Automação de Navegação**: Utilização do **Selenium** para navegar na Amazon e capturar os resultados.  
- **Extração de Dados (Web Scraping)**: Coleta de informações detalhadas sobre livros mais vendidos.  
- **Estruturação Simples dos Dados**: Organização das informações sem necessidade de tratamento avançado com **Pandas**.  

---

## 🛠️ Tecnologias Utilizadas
- **Python** → Linguagem base do projeto.  
- **Selenium** → Automação da navegação e scraping de páginas dinâmicas.
